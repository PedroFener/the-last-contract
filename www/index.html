CELULAR

Lado esquerdo: analógico de movimento (empurre até o fim para correr)
Lado direito: arraste para mirar; arraste mais longe para atirar
Botões: ESQUIVA, GOLPE, CÃO, RECARGA, ARMA, II pausa

GAMEPAD

Analógico esq. mover · Analógico dir. mirar
RT/RB atirar · A esquiva
B/LT corpo a corpo · X recarregar
Y/LB trocar arma · R3 / ↑ cão
Start pausa

Finalizações: um soco derruba o inimigo; com ele no chão, aperte GOLPE para pisotear (ou esfaquear, se estiver com a faca/lápis), ou ATIRE de perto para uma execução com a arma. Pitbull: a cada 3 abates o cão fica pronto — mire num inimigo e aperte G / CÃO: ele derruba o alvo e arranca a arma da mão dele. Finalize enquanto o cão segura! Inimigos desarmados tentam pegar a arma de volta. Tiros fazem barulho; faca e lápis são silenciosos.
